## Provenance et portée des vérifications

- Les récits proviennent du champ public `pointOfInterest.contents → TextContent.data.i18n.body`. Chaque variante a été demandée séparément et contrôlée sur son code de langue. - Le catalogue des pistes se trouve dans `pointOfInterest.audioGuideTracks.i18n.audio`, avec identifiant, langue, URL, empreinte déclarée, taille, format et durée. La station 01 a aussi été ouverte en allemand dans le navigateur. Le lecteur a sélectionné le même MP3 que le catalogue. La station 22 en polonais a présenté un récit français de repli.
- Les 105 adresses répondent à une requête de lecture `GET` avec `Range: bytes=0-0`. Les réponses `206` sont de type `audio/mpeg` et déclarent toutes la taille exacte du catalogue. Le contrôle a porté sur les en-têtes. Aucun corps audio n’a été enregistré pour l’inventaire. Les requêtes `HEAD` renvoyaient 404 sur ce serveur et ne permettent donc pas de juger l’absence d’une piste.
- Le champ de transcription de la piste `audioGuideTracks.i18n.text` est vide pour les 110 variantes recherchées. Aucun repère temporel exploitable n’a été trouvé dans les champs de piste consultés. Pour le polonais, les résumés et descriptions de fiche et de piste ont aussi été contrôlés. Aucun texte polonais n’a été trouvé dans ces champs. Le constat porte sur le guide public, où un export éditorial éventuel n’est pas visible.
